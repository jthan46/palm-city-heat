**Palm City Heat** is an original top-down open-world crime game for the desktop browser, set in a golden-hour city that never quite sleeps. You are a broke courier who falls in with fixer Vivian "Vivi" Solano: run her packages, steal the golden coupe, out-drive the Palm City PD, and turn four jobs into a partnership. The city is alive around you — five districts (downtown towers, the Marina Mile, Coral Heights suburbs, Palm Court Park, and the Ocean Drive beachfront), flowing traffic, wandering pedestrians who flee trouble, parked cars waiting to be borrowed, and a 1–5 star wanted system with police who pursue, ram, and bust you if they corner you slow. Fight with fists or a mouse-aimed pistol, grab cash, ammo and health pickups, and spend your earnings the hard way: fines at the station, bills at the hospital. Full HUD with a live minimap (roads, mission marker, police blips), a day clock, save/continue via localStorage, synthesized WebAudio sound (engine, sirens, gunshots — no audio files), and a fixed 60-steps-per-second seeded simulation, so every run of a seed plays out identically. Everything is drawn in code on a canvas; there are no image or sound assets and the game runs fully offline.

## Run it

```sh
node serve.ts
# then open http://localhost:8080 in a desktop browser
# (the dossier build the grader runs: MAKEFUN_OUTPUT_DIR=out node main.ts)
```
