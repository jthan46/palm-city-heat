Palm City Heat is an original top-down open-world crime game for the desktop browser, set in a golden-hour city that never quite sleeps. You are Cleo Marchetti, a courier who owes fixer Marisol Vega a van, a debt and an apology — and works it off one job at a time. Roam six districts on foot or by car: steal rides, weave through live traffic and crowds, take Marisol's four-mission story chain (a hot package, a borrowed gold coupe, a three-star heat run and a run across the whole city) plus endless courier work, fight with fists and a pistol, and outrun a five-star wanted system with interceptors that ram, pin and bust you. Full HUD with a live minimap, synthesized WebAudio sound, and a save that survives the session. The game is plain static files — no build step, no network, everything drawn and synthesized in code — and its simulation is deterministic: a fixed 60 steps/second from a seeded RNG.

## Run it

```sh
node serve.ts
# then open http://localhost:8080 in a desktop browser
```
